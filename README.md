
# HTTP-Server

## О проекте

Многопоточный HTTP-сервер, разработанный на C++20
в рамках курса «Многопоточное программирование на C++».

Сервер реализует протокол HTTP/1.1 и предоставляет
REST API для работы с коллекцией объектов item.

## Технологии

- C++20
- CMake
- POSIX Sockets
- Git
- GitHub

## Сборка проекта

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
```

## Запуск

```bash
./build/server --port 8080 --threads 8
```
